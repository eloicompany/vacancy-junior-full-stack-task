# Відповіді

## Частина 1. Знайдені помилки

> Опиши кожну помилку: що не так, критичність (Critical/High/Medium/Low), вплив
> на гроші користувачів. Впорядкуй за пріоритетом.

1. **[Critical]** - перевірка балансу і списання два окремі кроки
   - Що не так: між from.balance < amount і tx.account.update
     інша транзакція може змінити баланс
   - Вплив: при двох одночасних переказах баланс може піти в мінус

2. **[High]** - from.userId !== userId перевіряється після запитів до БД
   - Що не так: спочатку робляться два findUnique і тільки потім
     перевіряється чи рахунок належить користувачу
   - Вплив: зайві запити до БД для неавторизованих дій

3. **[High]** - тип Float для балансу і суми
   - Що не так: Float зберігає числа в бінарному форматі
     і накопичує похибку округлення
   - Вплив: баланси можуть відрізнятись від реальних значень

4. **[Medium]** - Currency не мав enum обмеження
   - Що не так: можна було записати довільний рядок "USDd", "EURr"
   - Вплив: некоректні дані в БД, помилки при обробці валюти

5. **[Low]** - відсутність @default(0) для balance і amount
   - Що не так: при створенні запису без явного значення
     поле могло бути null
   - Вплив: помилки при арифметичних операціях з балансом

## Частина 2. Виправлення

> Коротко опиши, що саме ти змінив у `transferMoney` і чому.
> Опиши, як запустити `scripts/repro.ts` і що він показує до/після фіксу.

- Зміни: 
- Змінив метод списання списання коштів та додав перевірку на сумму в балансі.
- Додав перевірку для юзера чи залогінен він чи ні.
- Додав перевірку для списання грошей та формат валюти.
- Додав транзакцію з ізоляцією Serializable для того щоб Postgres виконував транзакції послідовно

- Як відтворити баг і перевірити фікс:
```bash
  npm run db:reset
  npx tsx scripts/repro.ts
```
До фіксу скрипт покаже:
- Bob відправляє 999999 при балансі 500 баланс іде в мінус
- Перший `tx.account.update` без `await` списання не відбувається,
  але зарахування проходить

Після фіксу всі три сценарії повертають `{ success: false }`,
а коректний переказ Alice → Bob 200 USD оновлює баланси правильно
